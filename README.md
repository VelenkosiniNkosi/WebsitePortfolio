## 🛠️ Technologies Used

This project uses only plain, no-build-step web technologies — no frameworks, no bundlers, no dependencies to install.

- **HTML5** — structure and semantic content
- **CSS3** — custom properties (variables), responsive grid, flexbox, animations
- **Vanilla JavaScript** — theme toggling, scroll animations, form validation, smooth scrolling
- **Font Awesome 6** — icons throughout the site (loaded via CDN)
- **Google Fonts (Poppins)** — clean, professional typography (loaded via CDN)
- **FormSubmit** — free contact form backend, no server required
- **GitHub Pages** — free hosting directly from this repository

## 🎨 Design Choices

| Choice | Reason |
|---|---|
| **Emerald green (`#10b981`) theme** | Stands out from typical blue/purple graduate portfolios — professional and memorable |
| **Amber accent (`#f59e0b`)** | Adds warmth without clashing — used on hover effects and education cards |
| **Dark charcoal dark mode** | Easy on the eyes for recruiters browsing at night |
| **Light off-white light mode** | Clean and readable in a professional daytime setting |
| **Card-based layout** | Recruiters can scan individual experience cards in 5–10 seconds each |
| **Skill tags on every card** | ATS-friendly keywords visible at a glance on each experience entry |

## 📄 Sections Explained

### 🏠 Hero
The first thing visitors see. Shows my name, role, a one-line pitch, and two call-to-action buttons. The hero badge displays my award status and availability.

### 👤 About
A three-paragraph summary of who I am, my goals, and my background — with three quick stat tiles for fast scanning.

### 🛠️ Skills
Four skill category cards covering Front-End, Back-End & Databases, Tools & Platforms, and Analysis & Business Systems.

### 💼 Work Experience
Seven experience cards, each with a summary paragraph, 4–5 detailed bullet points, and skill tags. Cards are ordered by impact — internship first, then certified academic roles.

### 🎓 Education
Academic qualifications, awards (IBM, BBD), Hult Prize placement, Golden Key membership, and the Honorary Leadership Award.

### 📜 Certifications & Service Awards
Five LinkedIn Learning / Cisco certifications plus a combined UFS Certificates of Service entry covering all five officially certified Demonstrator roles.

### 📞 Contact
Contact details, LinkedIn and GitHub buttons, and a working contact form with basic validation.

## 🚀 How to Run Locally

No installation needed. Just:

1. Download or clone this repository
2. Open `index.html` in any web browser
3. That's it — everything works offline except the contact form (which needs internet to submit)

```bash
git clone https://github.com/VelenkosiniNkosi/WebsitePortfolio.git
cd WebsitePortfolio
open index.html   # or double-click the file
```
