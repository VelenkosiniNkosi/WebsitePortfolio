## Tech Stack

No frameworks, no build tools, no dependencies to install. Just plain web files.

- **HTML5** - page structure and content
- **CSS3** - layout, variables, animations, and responsive design
- **Vanilla JavaScript** - scroll animations, mobile nav, form validation, smooth scrolling
- **Font Awesome 6** - icons (loaded via CDN)
- **Google Fonts (Poppins)** - typography (loaded via CDN)
- **FormSubmit** - free contact form backend, no server needed
- **GitHub Pages** - free hosting directly from this repository

## Running Locally

No installation needed.

1. Download or clone the repository
2. Open `index.html` in any browser
3. Everything works offline except the contact form (which needs internet to submit)

```bash
git clone https://github.com/VelenkosiniNkosi/WebsitePortfolio.git
cd WebsitePortfolio
open index.html
```
